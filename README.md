# A Universe Called Me — GitHub Pages template

深い青・惑星・透明感をテーマにした、日本語中心の個人プロフィールサイトです。見出しは英字、説明は日本語で統一しています。

## 公開方法（GitHub Pages）

1. GitHubで新しいリポジトリを作成します。
2. このフォルダ内の `index.html`、`style.css`、`app.js`、`site-data.json`、`README.md` をリポジトリの最上位にアップロードします。
3. リポジトリの **Settings → Pages** を開きます。
4. Build and deployment の Source を **Deploy from a branch**、Branch を **main**、フォルダを **/(root)** にして Save します。
5. 公開URLが表示されるまで待ちます。

## サイト上での編集

- 右上の `EDIT MODE ＋` を押します。
- `文字を直接編集` を押すと、見出しや本文をページ上で直接編集できます。
- 音楽や画像カードは編集パネルの追加ボタンから追加できます。
- `この端末に保存` は、そのブラウザにだけ保存します。
- `編集データをダウンロード` でバックアップ用JSONを保存できます。`編集データを読み込む` で戻せます。

## 注意：公開中のサイトへ変更を反映する方法

GitHub Pages は静的ホスティングです。ブラウザ上で編集した内容は、閲覧者全員へ自動公開されません。全員に変更を見せるには、編集内容をGitHubリポジトリへコミットして再公開する必要があります。個人情報や公開したくない内容は入力しないでください。

## カスタマイズ

- 文章や見出し：`index.html` の `data-edit` が付いたテキストを編集
- 色やレイアウト：`style.css`
- 音楽・画像カード：`site-data.json`
- JavaScript：`app.js`

画像URLは、公開利用が許可された画像、または自分でアップロードした画像を使ってください。外部サービスの画像URLは、提供元の設定変更で表示されなくなることがあります。
